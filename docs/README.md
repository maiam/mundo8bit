Os documentos por etapa preservam o histórico: suas contagens de testes e resultados descrevem a versão indicada. A revisão consolidada distingue o que foi verificado por código, navegador emulado e o que ainda exige aparelho físico ou observação da criança. Testes automatizados não comprovam diversão ou adequação etária.

Para executar, construir e testar, consulte o [README do projeto](../README.md).
